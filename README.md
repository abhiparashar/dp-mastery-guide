A first-principles, pattern-by-pattern guide to mastering Dynamic Programming for FAANG-style interviews — from basics to advanced, with Java templates, recognition heuristics, worked examples, tagged LeetCode problem sets, edge cases/traps, and interviewer counter-questions.

## How to use this

Start at file `00` and go in order — each file assumes the framework from `00` and often reuses a trick from an earlier pattern file. See `14_roadmap_and_practice_plan.md` for a structured week-by-week plan and a consolidated LeetCode problem list.
